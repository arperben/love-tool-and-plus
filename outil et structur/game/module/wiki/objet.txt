                            wiki - objet
              mise à jour pour la version 1.4.1
à part pour l'affichage il est conseiller d'utiliser love.update
création objet -> les variable à mettre dans la fonction create pour pouvoir l'utilisé sur l'objet

ATTENTION : la taille de l'image doit être petit
            les emplacement pour certaine fonction ne sont pas obligatoir sauf pour les fonctios d'affichage

les variable demander comme :
  - gravity
  - jumpPower
  - x
  - y
  - width
  - height
  - scroll : SetGlobalScroll = False <- valeur par défaut
  - r, g, b
  - gui
non pas forcément besoin d'être entré (vous aurez des valeur par défaut)
