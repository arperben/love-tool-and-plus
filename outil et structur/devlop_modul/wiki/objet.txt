à part pour l'affichage il est conseiller d'utiliser love.update
création objet -> les variable à mettre dans la fonction create pour pouvoir l'utilisé sur l'objet

fonctionnement des vertion : 
      v -> version
      1 -> version du module (ne change qu'à l'ajout d'un dossier)
      .2 -> version du fichier (ne change qu'à l'ajout de fonction)
      .0 -> correction ou ajout mineur / modification de fonction existente

ATTENTION : la taille de l'image doit être petit

les variable demander comme :
  - gravity
  - jumpPower
  - x
  - y
  - width
  - height
  - scroll
  - r, g, b
  - decalx |
  - decaly | crée juste un décalage entre leur coordonée et le texture
  - TestGlobalMouv
non pas forcément besoin d'être entré (vous aurez des valeur par défaut)

-------- ajout v 1.2.0
objet.globalmouv(mouv_x, mouv_y, TestDecal) love.update/draw (de préférence avant les calcul de collision)
entrée = int, int, bool
sortie = nil
utilité -> permet le mouvement de tout les objet sauf se dont TestGlobalMouv = false
spécifisité -> si TestDecal est sur True alor l'affichage de des objets va boujet mais pas leur coordonée (utilise GlobalDecalx et GlobalDecaly)
